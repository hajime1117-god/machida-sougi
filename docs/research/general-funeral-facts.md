## 1. 葬儀形式の定義（一般葬・家族葬・一日葬・直葬）

| 形式 | 定義 | 参列人数の目安 | 通夜の有無・日程 | メリット | デメリット／注意点 |
|---|---|---|---|---|---|
| 一般葬 | 家族・親族に加え、友人・知人、会社関係者、近隣住民など幅広い関係者を招いて行う従来型の葬儀。通夜・葬儀告別式の2日構成。 | 数十人～100人超（サイトにより幅あり、具体的な人数基準の統一値は確認できず＝**未確認**） | 通夜＋告別式の2日間 | 弔問を受ける機会を一度にまとめられる、社会的なつながりに配慮できる | 費用・準備負担が大きい、対応に追われ遺族がゆっくり故人と過ごせない |
| 家族葬 | 遺族・親族・親しい友人など、招く人を絞って行う葬儀。通夜・告別式は行うことが多い。 | 少人数（具体的な数値の統一基準は確認できず＝**未確認**、一般葬より少人数と説明されるのが一般的） | 通夜＋告別式の2日間が一般的 | 遺族の対応負担が少なく、故人と落ち着いて過ごせる | 呼ばなかった人への事後対応（弔問・香典辞退の説明等）が必要になる場合がある |
| 一日葬 | 通夜を行わず、告別式と火葬のみを1日で行う葬儀。 | 家族葬と同程度の少人数が想定される（**未確認**：出典に明確な人数基準なし） | 通夜なし、告別式＋火葬の1日のみ | 費用を抑えられる、参列者・遺族の身体的負担が軽い | 平日日中の開催が多く、仕事の都合で参列できない人が出る可能性。菩提寺によっては通夜を省略することへの理解が得られない場合があり、事前相談が必要（下記「注意点」参照） |
| 直葬（火葬式） | 通夜・告別式を行わず、安置後に火葬のみを行う形式。 | ごく近しい家族・親族のみ | 儀式なし、火葬のみ | 費用を大きく抑えられる、身体的・時間的負担が最小 | 菩提寺がある場合、読経・戒名なしの火葬を認めない、または納骨を拒否されるケースがあるため事前確認が必須 |

### 菩提寺の許可について
一日葬・直葬では、菩提寺（先祖代々の墓を管理する寺院）の同意なく通夜や戒名授与を省略すると、後日の納骨を断られるなどのトラブルが起きうる、という説明が複数の葬儀社サイトで共通して見られます。ただし、これを裏付ける行政・宗教団体側の一次資料（全日本仏教会等の公式見解）は本調査では確認できませんでした。**→ この点はサイト掲載時に「菩提寺への事前相談を推奨」という表現に留め、断定的な記述は避けるべきです（未確認事項）。**

### 火葬までの「24時間ルール」（墓地埋葬法第3条）
条文を法令データベースで直接確認しました。

> 第3条　埋葬又は火葬は、他の法令に別段の定があるものを除く外、死亡又は死産後24時間を経過した後でなければ、これを行つてはならない。但し、妊娠7箇月に満たない死産のときは、この限りでない。

出典: [墓地、埋葬等に関する法律｜条文｜法令リード](https://hourei.net/law/323AC0000000048)（確認日 2026-09-15、条文本文をWebFetchで直接取得・確認済み）
補足参照: [第２章 埋葬，火葬及び改葬（第一法規PDF）](https://www.daiichihoki.co.jp/store/upload/pdf/028241_pub.pdf)、[墓地、埋葬等に関する法律 - Wikipedia](https://ja.wikipedia.org/wiki/%E5%A2%93%E5%9C%B0%E3%80%81%E5%9F%8B%E8%91%AC%E7%AD%89%E3%81%AB%E9%96%A2%E3%81%99%E3%82%8B%E6%B3%95%E5%BE%8B)

このため、亡くなった当日にすぐ火葬することは法律上できず、**必ず一定期間の「安置」が必要**になります（自宅安置・葬儀社等の安置施設の利用など）。

## 3. 費用の内訳構造

| 区分 | 内容 | 追加費用が発生しやすいか |
|---|---|---|
| 葬儀一式費用（基本料金） | 祭壇、棺、遺影写真、司会進行、スタッフ人件費など、プランに含まれる基本部分 | プラン外オプション（生花祭壇のグレードアップ等）で増額しやすい |
| 変動費 | 火葬料、式場使用料、安置料（ドライアイス代含む）、寝台車・霊柩車の搬送距離に応じた料金 | **発生しやすい**：安置期間の長期化（火葬場の順番待ち等）によるドライアイス代・安置料の積み増し、搬送距離超過分の追加料金 |
| 飲食接待費 | 通夜振る舞い、精進落とし等の飲食費 | 参列人数の見込み違いによる増減が起きやすい |
| 返礼品費 | 香典返し、会葬御礼品 | 参列人数の見込み違いで増減 |
| 宗教者への謝礼 | お布施（仏式）、御礼（神式・キリスト教式） | プラン費用に含まれず「実費・別途」となるのが一般的 |

このうち、日本消費者協会調査で「合計額」に対して「葬儀一式費用」が最大の構成要素であること、鎌倉新書調査でコロナ後に規模拡大・費用増加の傾向が出ていることが確認できます（上記2章参照）。安置日数の長期化（特に冬季・都市部の火葬場逼迫時）による追加費用は、鎌倉新書調査のタイトルでも触れられている論点です（本文詳細は未確認）。

## 4. 亡くなった直後の流れと標準的な時間軸

| ステップ | 内容 | 目安タイミング |
|---|---|---|
| 死亡確認・死亡診断書 | 医師が死亡を確認し死亡診断書（施設内死亡）または死体検案書（異状死等）を発行 | 死亡直後 |
| 末期の水・エンゼルケア | 末期の水（死に水）を取り、看護師等が体を清め死化粧などの処置（エンゼルケア）を行う | 死亡確認後、目安30分～1時間程度 |
| 搬送依頼 | 葬儀社・搬送業者へ連絡し、病院（安置は数時間程度が目安）等から安置先へ搬送 | 死亡確認後、数時間以内（病院の霊安室は長時間利用不可なことが多い） |
| 安置 | 自宅または葬儀社の安置施設・安置室で遺体を安置。ドライアイス等で保全 | 搬送後～通夜まで、最短でも法律上24時間は火葬不可のため必須 |
| 死亡届・火葬許可証 | 死亡届（死亡診断書と一体の様式）を市区町村役場に提出し、火葬許可証の交付を受ける | 死亡後7日以内に届出（葬儀社が代行することも多い） |
| 打ち合わせ | 葬儀社と日程・プラン内容を打ち合わせ | 搬送後～通夜前まで |
| 納棺 | 遺体を棺に納める儀式（湯灌を行う場合はこの前後） | 通夜当日または前日 |
| 通夜 | 近親者・弔問客が集まり故人を偲ぶ（一般葬・家族葬の場合） | 死亡から平均2日後程度が通例（一日葬・直葬では省略） |
| 葬儀・告別式 | 宗教儀礼を伴う本葬儀と、故人に最後の別れを告げる式 | 通夜の翌日、死亡から2～4日後が目安 |
| 火葬 | 火柩後、火葬場で火葬（法律上、死亡後24時間経過が必須） | 告別式当日 |
| 収骨（骨上げ） | 火葬後、遺族が箸で遺骨を骨壺に納める | 火葬直後 |
| 初七日 | 本来は死後7日目の法要だが、現在は葬儀当日に「繰り上げ初七日」として行うことが多い | 死後7日目、または葬儀当日 |
| 精進落とし | 初七日後などに行う会食 | 初七日法要後 |
| 死後の各種手続き | 埋葬許可証の取得（火葬済証明が押された火葬許可証がそのまま埋葬許可証になる場合が多い）、年金・保険・相続関連手続き等 | 火葬後～数か月にわたり継続 |

## 5. 自宅で亡くなった場合／施設で亡くなった場合の違い

| ケース | 対応 |
|---|---|
| かかりつけ医がいて、その持病が死因と判断できる場合 | かかりつけ医に連絡。死亡前24時間以内に当該医師の診察があれば、死亡時に立ち会っていなくても死亡診断書が発行可能 |
| かかりつけ医がいない、または死因が不明・不自然な場合（異状死） | 警察に連絡が必要。警察医（検視官等）による検視・検案が行われ、死体検案書が交付される |
| 訪問診療中でも、かかりつけ医以外の病院に救急搬送された場合 | 検視が必要になるケースがある |
| 病院・施設で死亡した場合 | 通常は担当医が死亡診断書を発行し、検視は不要（施設側の対応フローに従う） |

## 7. 用語集（一般ユーザー向け一文定義）

| 用語 | 定義 |
|---|---|
| 喪主（もしゅ） | 葬儀を行う遺族の代表者で、葬儀社との打ち合わせや菩提寺・参列者への対応を担う人 |
| 施主（せしゅ） | 葬儀の費用を負担し、運営面での責任を持つ人（喪主が兼ねることも多い） |
| 安置 | 火葬までの間、法律上必要な期間、遺体を自宅や専用施設で保管すること |
| 納棺 | 遺体を棺に納める儀式 |
| 通夜 | 葬儀・告別式の前夜（または前日）に、近親者や弔問客が故人を偲んで過ごす儀式 |
| 告別式 | 故人に最後の別れを告げる儀式で、一般的に火葬前に行われる |
| 火葬許可証 | 死亡届提出時に市区町村へ火葬許可申請を行うことで交付され、火葬を行うために必要な書類 |
| 埋葬許可証 | 火葬後、火葬済みの証明が押された火葬許可証で、納骨の際に必要となる書類（多くの自治体で火葬許可証がそのまま埋葬許可証を兼ねる） |
| 枕飾り | 安置中の遺体の枕元に置く、線香・ろうそく・花などの簡易な祭壇飾り |
| 湯灌（ゆかん） | 遺体を入浴させて清め、旅立ちの準備をする儀式（主に精神的・儀礼的な意味合い） |
| エンバーミング | 遺体を消毒・防腐処理し、衛生的に長期間保存可能にする技術（湯灌とは目的が異なる） |
| 骨上げ（こつあげ） | 火葬後、遺族が箸を用いて遺骨を骨壺に納める儀式（収骨とも呼ばれる） |
| 分骨 | 遺骨の一部を分けて、複数の場所（本山納骨、手元供養など）に納めること |
| 初七日（しょなのか） | 本来は死後7日目に行う法要。現在は葬儀当日にまとめて行う「繰り上げ初七日」が一般的 |
| 四十九日（しじゅうくにち） | 死後49日目に行う忌明けの法要で、納骨の目安時期とされることが多い |
| 戒名（かいみょう） | 仏教において死後に授けられる名前（宗派によっては「法名」「法号」と呼ばれる） |
