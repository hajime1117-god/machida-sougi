## 7. ページ分割の根拠(独立した検索意図が存在するもの)

| 分割 | 根拠(SERP観察に基づく) |
|---|---|
| P1(葬儀ハブ) と P2(家族葬) を分ける | 「町田市 家族葬」は上位に**地元葬儀社の家族葬専用ページ**(東横メモリアル・湘和会堂・四季風・そうえん鶴川)が入り、「町田市 葬儀」より取引色が強い。ハブに埋めると家族葬LPとしてのタイトル・見出しの一致度が落ちる |
| P3(費用) を形式ページから分ける | 「町田市 葬儀 費用」「家族葬 費用」の上位は**コラム型記事**(相場・内訳・抑え方)で、形式ページ(プラン・式場一覧)とは形が違う。同一ページに両方詰めると長大化し、どちらの意図にも最適化できない |
| P4(一日葬) / P5(直葬) を個別に持つ | いい葬儀は形式別LP(一日葬 最安17.0万円〜、家族葬 20.0万円〜)を分けて出しており、直葬は「町田直葬サポート」という専門LPまで存在。形式ごとに価格帯・所要日数・流れが異なり、単独で検索される |
| P6(一覧) と P7(南多摩斎場) を分ける | 「町田市 斎場」「町田市 火葬場」のSERPは**南多摩斎場の単体詳細ページ**と**一覧ページ**が混在。固有名詞「南多摩斎場」は5市の住民が検索する独立エンティティで、料金表・申込・休場日・アクセスまで載せると1ページ分の情報量になる |
| P8・P9(市外斎場) を独立させる | 町田市南部は横浜市北部斎場、西部は相模原市営斎場が地理的に近く、**市外料金(横浜50,000円・相模原54,000円)と市外予約制限**という町田市民固有の論点があるが、それを解説した競合ページは検索上位で未確認(空白) |
| P10(葬祭費) を P3(費用) から分ける | 「葬祭費」は市公式ページが上位に出る**手続き型**クエリ(必要書類・窓口・2年の時効・オンライン申請)。費用相場コラムとは意図が異なり、公式ページに準拠した手続き情報が求められる |
| P11(流れ・手続き) を P12(緊急お迎え) から分ける | 「亡くなったら/何をすればいい」は市公式「おくやみ」「死亡届」と並ぶ**情報型**。「町田市民病院で亡くなった/搬送」は**数時間以内に搬送先を決める緊急型**で、電話CTAと所要時間・安置先を最上部に置く必要がある。P11の長文の中に置くと緊急ユーザーに届かない |
| P13(事前相談) を独立させる | 「町田市 葬儀 相談」は各社「事前相談無料」訴求と市の「まちそう」案内が並ぶ**取引型**。フォーム・電話・来館予約を主目的とするCVページであり、情報ページに混ぜない |
| エリアページを駅単位で分ける | 鶴川(6式場以上)、成瀬(3式場)、町田駅(3式場)、南町田(1式場+北部斎場)、多摩境(1式場)と**駅ごとに実在式場が異なり**、ポータル(いい葬儀・安心葬儀)も駅単位ページを持つ。ユーザーは「自宅から近い式場」を探すため、市全体一覧では意図を満たせない |
