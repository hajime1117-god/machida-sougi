# 地域密着型葬儀社サイト7件の横断分析と「町田ことのは葬祭」改修方針

出典: 北関東互助センター／支援葬祭／フラワリングセレモニー浦安／セクト株式会社／立ち華葬祭／ワンライフ／ひかりセレモニー（各社サイト調査、2026-09-16取得。詳細な一次出典は各社分析JSON内に記載）。

前提: 町田ことのは葬祭は架空事業者（Astro構築）。写真素材は使わずSVGイラストで表現し、実績数値・口コミ・実名スタッフなど検証不能な情報は創作しない。既存のSEOタイトル/メタ、計測タグ（GA等）は変更しない。

## 2. 「利用者の希望 → 該当プラン」の見せ方（具体案）

トップページまたはプラン一覧の冒頭に「あなたのご希望は？」というチェックリスト/タグ選択UIを設置し、希望文言をクリックすると該当プランへスクロール／遷移する設計を推奨（北関東互助センターの分析で指摘された「ペルソナ分岐がプラン一覧より前にない」弱点を解消する対応）。

## 3. FV構成案

### キャッチコピー候補5案（抽象語を避け、具体的ベネフィットを提示）

1. 「町田市内なら、ご連絡から30分程度でお迎えにうかがいます」（迅速性・具体的行動を明示。実際の対応可能時間は運用に合わせて調整）
2. 「家族葬・一日葬・火葬式、町田市の相場と内容をその場で比較できます」（比較のしやすさを具体的に約束）
3. "自宅近くの公営斎場（南多摩斎場ほか）から、費用を抑えた葬儀をご提案します"
4. 「通夜・告別式・火葬に含まれるもの／含まれないものを、金額と一緒に全部載せています」（透明性を具体的に訴求）
5. 「町田市・相模原市・多摩市エリア、24時間電話一本でご相談いただけます」（対応エリアと即応性を明示）

※ いずれも「No.1」「実績◯件」「創業◯年」等の検証不能な数値は含めない。番号・具体時間は運用確定後に事実ベースで調整する前提。

### ビジュアル（SVGイラスト）の構図案

FVでは実写の代わりに、次の3構図をタブ切り替えまたは横並びで配置することを推奨。

- **祭壇イラスト**: 中央に生花祭壇のシルエット、左右に控えめな装飾ライン。暖色（オフホワイト×淡いベージュ/グリーン）の落ち着いた配色で「静けさ」を表現。過度に装飾的にせず線画＋フラットカラーで構成。
- **式場イラスト（外観+簡易平面図）**: 建物の外観を単純化した線画で示し、隣に会場内の動線（受付→式場→控室）を示す簡略な平面図アイコンを添える。実在施設の外観を模倣しない、あくまで概念図であることが分かるトーンにする。
- **少人数のお別れイラスト**: 祭壇に向かって数人の人物シルエット（顔の描き込みはせず、抽象的な人型）が並ぶ構図。家族葬・一日葬の「親しい人だけで」という価値観を視覚的に補強する。

3構図はCSSアニメーションやスクロールに応じて切り替えてもよいが、初期表示（ファーストビュー内）には少なくとも1点を静止画として配置し、読み込み負荷を抑える。

## 4. プランカードの要素と順序（推奨）

複数サイトの共通パターンを踏まえ、以下の順序で統一する。

1. **向いている方**（例:「親しい方だけで、通夜からゆっくりお別れしたい方」）
2. **何をする葬儀か**（プラン名の直後に一言で要約。例:「通夜・告別式・火葬を行う、家族中心の葬儀です」）
3. **日数／人数／通夜・告別式・火葬の有無**（アイコンで視覚的に。例: 2日間／5〜30名目安／通夜◯・告別式◯・火葬◯）
4. **料金**（税込表記＋「〜」で下限を明示。可能な限り「含まれるもの／含まれないもの」をカード内に簡潔な箇条書きで明記し、詳細ページ送りにしない＝他社の弱点を解消する差別化点）
5. **祭壇イメージ（SVGイラスト）**＋「※イメージ図です」の注記
6. 詳細ページへのCTAボタン

この順序は立ち華葬祭・フラワリングセレモニー浦安等の「対象者→ビジュアル→内容→価格→詳細」型を踏襲しつつ、含む/含まないの明記をカード内に前倒しする点で改善する。

## 5. 斎場ページ:「どこを使えばいいか」の判断軸UIと南多摩斎場の見せ方

### 判断軸UI（一覧ページ）

各斎場カードに、共通の判断軸を必ず同一フォーマットで表示する（実写真がないため、この情報の粒度で差別化する）。

- 施設種別タグ（自社／公営）を色分け表示
- 収容人数の目安（丸数字またはバーで視覚化）
- 火葬場併設の有無
- 駐車場台数
- 最寄駅・アクセス目安（徒歩/車の分数）
- 控室・宿泊可否・バリアフリー対応（アイコン）
- 簡易マップイラスト（実在の詳細地図ではなく、最寄駅からのデフォルメ経路図）

絞り込み機能（自社/公営、地域エリア別）を一覧上部に設置し、複数サイトで指摘された「絞り込みなしの羅列」という弱点を解消する。

### 南多摩斎場の見せ方

南多摩斎場は公営施設として、以下の専用セクションで深掘り解説する（ひかりセレモニーの「大和斎場に特化する理由」型を踏襲）。

- 所在地・最寄駅・アクセス（簡易マップイラスト付き）
- 火葬炉数、式場の有無、待合室・控室の設備
- 公営斎場を利用するメリット（式場費用を抑えやすい、火葬場併設で移動負担が少ない等、事実ベースの説明）
- 自社が仲介・進行をサポートする流れ（公営斎場＋自社の家族葬プランを組み合わせた場合の費用感の目安）
- 「南多摩斎場を使った家族葬プラン」への直接リンク

自社施設と公営斎場で情報量に極端な差をつけない（ワンライフの分析で指摘された弱点＝比較の公平性が損なわれる点を回避）。

## 6. 流れページ：ステップの見せ方で取り入れる点

- **二層構造**: 「葬儀のまえ／葬儀／葬儀のあと」の3フェーズ×具体ステップ（合計8〜10程度）に整理する。
- **各ステップ = 見出し＋短文＋SVGピクトグラム**の3点セットで統一（寝台車・祭壇・棺・骨壷などを線画アイコン化）。
- **時系列の言葉での補足**（「ご逝去当日」「通夜は翌日の夕方」等）を添え、明確な「◯日目」表記に固執しすぎず柔軟性も残す。
- **所要時間の目安**（火葬1〜1.5時間等、事実として言える一般的な目安）を添えて不安を先回りして解消する。
- **状況分岐**（病院で亡くなった場合／自宅で亡くなった場合／警察が介在する場合）をステップ冒頭または注記で示し、読み手が自分の状況に当てはめやすくする。
- **緊急導線の再掲**: 各フェーズの節目（特に最初のステップ）に電話番号・24時間365日対応を再掲する。
- スマホでは縦積みのタイムライン形式にし、各ステップをタップで展開するアコーディオンも検討する。

## 7. CTA文言の状況別セットと配置の節度

| 状況 | CTA文言例 | 配置 |
|---|---|---|
| お急ぎ（今すぐ困っている） | 「ご危篤・お亡くなり・搬送 お急ぎの方へ」「24時間365日 今すぐ電話相談する」 | ヘッダー固定＋FV直下に最優先表示。他のCTAより視覚的に強調（色・サイズ） |
| 比較中（プランを検討している） | 「プランを比較して選ぶ」「料金の詳細を見る」 | プラン一覧セクションの導入部・各カードの詳細リンク |
| 費用だけ知りたい | 「まずは費用の目安を見る」「資料をもらう（無料）」 | プラン比較表への導線、フォーム/資料請求ボタン |
| 事前相談（まだ先の話として検討） | 「事前相談する（無料・任意）」「メールで相談する」 | フッター、記事コンテンツ（コラム等）の末尾 |

**配置の節度**: CTA文言の種類は上記4系統に絞り、1ページ内で類似文言を乱立させない（セクト株式会社の分析で指摘された「CTA文言10種類以上で優先度が伝わりにくい」という弱点を避ける）。電話番号は全ページ共通でヘッダーに固定表示し、tel:リンク化してスマホでタップ発信できるようにする。スマホでは画面下部に「電話」「お急ぎの方へ」の2ボタンのみを固定表示し、それ以外のCTAはページ内の文脈に応じて出す。

## 8. 画像と文章の二層構造の設計

各セクションで「まず画像・要約・比較を見せ、詳細はその下（または詳細ページ）に折りたたむ」という二層構造を徹底する。

- **上層（一覧・要約層）**: SVGイラスト1点＋見出し＋対象者一文＋主要数値（人数/価格/日数）を1画面に収める。文章は2〜3行以内に抑える。
- **下層（詳細層）**: 含まれるもの/含まれないものの詳細リスト、進行の詳細手順、Q&A、注意事項などのテキスト量が多い情報はここに配置し、上層からのリンク/アコーディオンで開く。
- 比較表（プラン比較、斎場比較）は上層に近い位置に独立して設置し、複数プラン・複数斎場を横並びで見られるようにする。
- すべてのイラストに「※イメージ図です」等の注記キャプションを添え、実写や実在施設と誤認されないようにする。

## 9. 避けること

- **実績数値・口コミ件数・No.1訴求・創業年数・施行件数など検証不能な数字の創作**（複数サイトで多用されているが、架空事業者では絶対に使用不可。代わりに「明朗な料金表示」「地域専任スタッフ」等の定性的な特徴訴求、または出典明記の一般統計・公的データの引用に置き換える）
- **実名代表者・スタッフの顔写真や実名プロフィールの掲載**（架空の人物を実在するかのように描かない。役職名＋イラストアバターで代替）
- **プランカードで「含まれないもの」を隠す／詳細ページ送りにする構成**（誤解や後出し感を招くため、カード内に簡潔な箇条書きで明記する）
- **自社施設と公営施設を同一フォーマットで並べ、情報量に極端な差をつける構成**（比較の公平性を損なう。両者に共通の判断軸を用意する）
- **収容人数・駐車場・地図・設備タグなど、斎場選びに必要な判断材料を欠いたまま一覧を並べるだけの設計**
- **電話番号を画像バナーとして焼き込み、テキスト化・tel:リンク化しない実装**（モバイルでの視認性・操作性を損なう）
- **CTA文言を多種多様に乱立させ、優先度を分かりにくくする設計**
- **実写真をイラストで代替する際に、実在施設・実在人物を模したかのようなリアルな描写にすること**（あくまで概念図・イメージ図であることが伝わるフラットなトーンに留める）
- **既存のSEOタイトル・メタディスクリプション・計測タグ（GA等）を、デザイン改修のついでに変更すること**（本改修のスコープ外であり維持が前提）
