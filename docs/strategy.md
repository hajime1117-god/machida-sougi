## 1. SERP分析の要点（「町田市 葬儀」「町田市 家族葬」）

- **上位の顔ぶれ**: 全国型ポータル（小さなお葬式・いい葬儀・イオンのお葬式・よりそう）、大手葬儀社の地域ページ（公益社・ティア・むすびす）、比較サイト（安心葬儀・soogi.jp）が中心。「町田市 家族葬」では町田市内に式場を持つ地元葬儀社の家族葬ページ（湘和会堂町田・東横メモリアル・四季風・永田屋）が混在し、取引色が強い。町田市公式ページは情報が薄く上位に出ない。
- **共通要素**: 斎場一覧（南多摩斎場が必出）、プラン別料金と「◯万円〜」訴求、葬祭費5万円、費用相場、口コミ、FAQ、24時間フリーダイヤル、葬儀の流れ、駅別リンク。
- **検索意図（推定）**: Local 約40% / Transactional 約25〜30% / Know 約25〜30% / Do 約5%。緊急（病院・施設からの連絡直後）と事前相談（終活）の二極。
- **上位ページに不足している情報（差別化の柱）**:
  1. 南多摩斎場の**公式使用料の正確な転記**（構成市住民は火葬料無料、式場使用料、霊安室）と、それを組み込んだ**総額試算**
  2. **火葬待ち日数と安置費用**（待ち日数×安置料×ドライアイス）の試算、混雑時の**代替火葬場の市外料金比較**（横浜市北部・相模原市営 など）
  3. **参列人数別・形式別の総額例**と「含まれないもの」の明示。相場のばらつき（37万〜127万円）の理由の説明
  4. **町田市の地理（南北に長い）に応じたエリア別の式場・火葬場動線**
  5. **市民葬の現状**（市直営の葬祭事業は2022年3月終了 → 町田市民葬祭事業組合の案内）の正確な整理
  6. **葬祭費申請の実務**（窓口・郵送・オンラインの3ルート、必要書類、2年の期限）、社会保険の埋葬料との違い、葬祭扶助
  7. 病院・施設からの**搬送実務**（すぐ葬儀社を決めなくてよい、搬送だけ依頼できる）
  8. 家族葬特有の「**呼ばない人への連絡・後日弔問**」対応
  9. **出典と最終確認日**の明示（上位ページはほぼ無し）
- **競合の弱点（競合分析4本より）**: 価格が画像のみでテキスト化されていない（永田屋）、H1欠落や重複、FAQが全社共通テンプレで町田固有でない（四季風）、table要素ゼロ・更新日なし（公益社）、式場固有情報が本文の1/3以降まで出ない、電話番号が複数混在。
- **AIが引用しやすい構造**: 上位で唯一「結論先出し＋数値＋表」を徹底しているサイトはなく、Q→A 直答構造と出典付きの表を全ページで徹底すること自体が差別化になる。

## 4. コンテンツ設計の原則

1. **Q→結論→理由→条件/具体例→詳細**: H2 を疑問文または名詞句にし、直後の `.answer` ブロックで直接回答する。前置きを書かない。
2. **表を使う場面**: 料金、比較（形式・火葬場・人数別総額）、手続き（期限・窓口・書類）、施設情報。表には caption（何の表か・税込/税抜・確認日）を付ける。
3. **出典と最終確認日**: 行政制度・料金・施設情報の直後に `<Source>` で出典URLを示し、ページ上部に `LastReviewed`。
4. **町田市の固有情報を必ず含める**: 南多摩斎場（構成市住民の火葬料無料）、市役所市民課104窓口、市民センター、まちそう、町田市民病院など。どの地域にも当てはまる文章だけのページを作らない。
5. **架空の実績を書かない**: 口コミ・件数・満足度・受賞・スタッフ・創業年は書かない。「私たちは〜します」という姿勢・方針は書いてよい。
6. **用語には説明**: 初出の専門用語（安置、納棺、火葬許可証、後火葬 など）に短い説明を付ける。
7. **AIっぽい文章を避ける**: 「〜と言えるでしょう」「まとめ」の乱発、同じ結論の繰り返し、抽象的なメリットの列挙を禁止。具体的な数字・固有名詞・条件で書く。
8. **文章量**: 主要ページ 3,000〜5,000字、エリア・コラム 2,000〜3,500字を目安。検索者の疑問が解決する量を基準にし、水増ししない。

## 8. AIO（AI検索）対策の実装事項

- 各重要ページの H2 直後に直接回答（`.answer`）。数値・条件・固有名詞を含める
- FAQ ページは FAQPage JSON-LD（ページ内に実在するQ&Aのみ）、各ページに BreadcrumbList、コラムに Article
- Organization / WebSite JSON-LD に「架空・検証用」であることを description に明記（虚偽の LocalBusiness を出さない）
- `robots.txt` で GPTBot / OAI-SearchBot / ClaudeBot / PerplexityBot / Google-Extended / Bingbot を明示的に許可（ChatGPT 検索は Bing インデックスにも依存するため Bing Webmaster Tools への登録も推奨）
- 更新日・最終確認日・出典の明示、用語の定義文（「◯◯とは、〜です」）を各ページに置く
- 表は `<table>` + `<caption>`、手順は `<ol>` で機械可読に

## 9. 調査で判明した注意点（2026-09-16 追記）

- **FAQPage リッチリザルトは終了**（業界報道では 2026年5月に全サイトで表示終了）。本サイトでは `/faq/` にのみ FAQPage JSON-LD を残す。リッチリザルト目的ではなく、AI クローラーが Q&A 構造を機械的に把握する補助として害がないため（`docs/research/aio-analytics.md` §5-1）。
- **AI クローラー**: 学習用（GPTBot / ClaudeBot / Google-Extended）と検索・引用用（OAI-SearchBot / Claude-SearchBot / PerplexityBot）を区別する運用が広がっているが、本サイトは「AI 回答の情報源になる」ことが目的のため両方を許可する（`robots.txt`）。
- **南多摩斎場の市外火葬料**は 2026-09-15 時点の公式ページで 80,000円。二次情報（50,000円）は古いため使わない。
- **市営の葬儀式場は存在しない**。公営で使えるのは南多摩斎場組合の式場のみ。市民センター・自治会館の葬儀利用可否は公式ページで確認できず、サイトでは断定しない。
- **町田市直営の葬祭事業（市民葬）は 2022年3月31日で終了**。現在は町田市民葬祭事業組合（町田のまちそう）を市が案内。
- **葬祭扶助**: 町田市生活援護課ページに「葬祭扶助」の語はなく、基準額は厚労省の全国基準（令和6年4月）で記載。市独自運用は未確認と明記する。
- **エリアページ**: 調査では「成瀬・南町田・つくし野・玉川学園は生活圏が重なる」との指摘があるため、各ページは固有の施設・窓口・所要時間で差別化し、薄くなる場合は統合する。
